# Hydrate — Water Intake Tracker

Hydrate is a React-based water intake tracking application created to provide a simple way to monitor daily hydration and progress toward a daily water goal.

## Features

* Log daily water intake
* Track progress toward a 2,000 ml daily goal
* Undo or reset water entries
* View hydration history over seven days
* Save daily totals using browser `localStorage`

## Built With

* React
* Recharts
* CSS
* Create React App
